{% load i18n %} {% comment %} Gallery photos as image tiles, for shop.admin.ProductImageInline. Drawn inside the product form's Photos card (admin/shop/product/photos_card.html). Formset plumbing, as in mp_role.html: data-inline-type="stacked" is the inlines.js dispatch path for non- rows. It selects "#-group .inline-related", clones "#-empty" to add a row, inserts the new row before that template, and appends its JS remove link to the row's FIRST child (the tile's tool strip). `has_original` keeps that remove link off saved rows, whose DELETE checkbox is the tile's bin button instead. The management form, pk/fk inputs, the empty-form template and every error list are still emitted. inlines.js's own "Add another" row stays in the DOM but hidden: the "Add photos" tile (a multiple file picker, unhidden by admin_product_form.js) clicks it once per picked or dropped image and moves the file into the new row. If the browser cannot move files between inputs, the script shows Django's link instead. A view-only account gets the photos and positions without any controls. {% endcomment %}
