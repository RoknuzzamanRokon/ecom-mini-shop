{% load i18n %} {% comment %} Editable board for rbac.widgets.MiniShopPermissionWidget. This is MiniShop's OWN RBAC catalogue (rbac.Permission), not Django's auth.Permission. Ticking a box here creates a DIRECT grant (a UserPermission row) for this one account; it never edits a role. Inherited rows are rendered `disabled`. A disabled checkbox submits nothing, so the browser guarantees a role-derived permission cannot be silently copied into the direct-grant set -- the saved set stays a record of the exceptions. Reuses the pm-* chrome and the data-pm-* hooks of the panel-permission board, so static/js/admin_user_permission.js drives the search, the resource rail, select-all and the live counters with no JS specific to this board. It deliberately does NOT carry data-pm-hero: the hero gauge reports admin-panel permissions, and two boards writing to it would fight. {% endcomment %} {% if not widget.board %}
